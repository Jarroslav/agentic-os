# SDLC Autonomous

Starts a fully autonomous agentic-sdlc run. The pipeline resolves judgment gates with subagent stand-ins and fast-path logic, prompting you only when a risk flag requires escalation.

## Use It For

- Implementing a ticket end-to-end with minimal interruptions.
- Running factory mode for low-risk, well-scoped features.
- Automating the full development cycle from requirements to a branch-ready state.
- Greenfield POC setup where the pipeline handles all phases automatically.

## How To Ask

Examples:

- "Run autonomously: refactor the logger to use pino."
- "Factory mode for PROJ-456."
- "Ship this without asking."
- "Use sdlc-autonomous with --greenfield 'tiny note-taking CLI in Python'."

## What It Needs

- `.agentic/guides/` files generated by `knowledge-foundation` (project.md, git-workflow.md, quality-gates.md).
- superpowers plugin >= 5.0.7.
- A clean working tree on a feature branch (or base branch to create one from).

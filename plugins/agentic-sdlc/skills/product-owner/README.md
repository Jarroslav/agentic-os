# Product Owner: Story Drafter

Turns a raw feature idea or description into a well-structured user story with given/when/then acceptance criteria, saved to `docs/stories/` and optionally synced to an external ticket tracker.

## Use It For

- Drafting user stories from a rough feature idea.
- Writing acceptance criteria in given/when/then format.
- Creating feature requirement documents (FRDs).
- Breaking an idea into a deliverable, independently testable story before starting implementation.

## How To Ask

Examples:

- "Create a story for bulk CSV export."
- "Draft a user story for the login timeout feature."
- "Write acceptance criteria for the password reset flow."
- "I have an idea — help me spec it out."

## What It Needs

- `.agentic/guides/project.md` — for project settings and optional ticket adapter configuration.
- A feature idea, problem description, or feature name to start from.

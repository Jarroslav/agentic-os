# Changelog

Notable changes to this bundled plugin, as distributed here. Format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/); this distribution
uses Semantic Versioning.

## [0.4.4] — distributed with agentic-os

Skill-based entry points (`sdlc-start`, `sdlc-autonomous`, `sdlc-status`,
`sdlc-doctor`, `sdlc-task`) for Claude Code and Codex. `sdlc-task` is the
lightweight entry point for user-classified XS/S/M work (`mode: "sync"`
reconciles `spec.md`/`plan.md` with any changes made after the initial run).
